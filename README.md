# AI 论文与英语词本

这个项目整理了 50 篇 AI 领域的重要论文，并从论文中提取高频英语词汇，制作成 2,500 词的中英双语词本，配有原文例句和中文翻译。

阅读器：[打开深色分页词本](vocabulary/reader.html)。论文 PDF 按主题分类，见 [论文目录](#论文目录)。
